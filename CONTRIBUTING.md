# Contributing to paprika3d

This repository holds the stable builds of paprika3d. The source is developed in a private repository and published
here on each release, so changes are not merged here directly.

- **Bugs and requests:** open an issue at https://github.com/paprika3d/paprika3d/issues with what you expected, what
  happened, and the run folder (`<project>/paprika3d/runs/<time>/`) if you have one.
- **Code:** paprika3d is under the Apache License 2.0. Before Keeno Corp can accept code from outside contributors,
  each contributor signs a contributor licence agreement; it is not set up yet, so describe the change in an issue
  and we will make it.
- **Name:** "paprika3d" is a trademark of Keeno Corp. A fork is welcome under the licence but needs its
  own name.
