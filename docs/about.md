# About

paprika3d is maintained by the paprika3d team ([github.com/paprika3d](https://github.com/paprika3d)).

The code of the plugin and MCP server is at [github.com/paprika3d/paprika3d](https://github.com/paprika3d/paprika3d). That repository holds the stable builds; each tagged release publishes one. The code is under the Apache License 2.0.

Some pages on this site are written by an agent. Every such page says so in a line at its foot, with the date it was written and the date it was last reviewed, and every code sample on such a page ran in the harness before it was published. Pages without that line are rendered from the files in the repository: the README, the skill and its references, and the source of the tools.

To report a problem with the harness or with this site, or to ask a question, open an issue at [github.com/paprika3d/paprika3d/issues](https://github.com/paprika3d/paprika3d/issues).
